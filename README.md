# Data Centers in Local Communities — Case Study

Self-directed data analytics project (Google Data Analytics Capstone, Track B) —
analyzing the pros, cons, and community impacts of data centers using Python (pandas, matplotlib).

## Key Findings
- Virginia leads the US with 809 data centers — nearly double Texas (677)
- US data center electricity use tripled since 2014 (58 → 192 TWh);
  projected to reach 649 TWh (~12% of US power) by 2030
- Loudoun County, VA earns ~$1.1B/year in data center tax revenue
- But ~$9.3B in grid costs were shifted onto household electric bills,
  and 833 community opposition groups now exist across 49 states

## Recommendations
1. Make operators pay their own grid infrastructure costs
2. Require public disclosure of energy/water/noise before approval
3. Enforce buffer zones and noise limits near residential areas

## Data
Location data: Global Data Center Map (ATLAS, community-compiled):
